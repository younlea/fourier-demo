# 공업수학 2 · DFT/FFT/IFFT 실습 데모

> 푸리에 변환을 소리와 이미지로 직접 만나보는 웹 기반 실습 데모

## 📌 개요

이 저장소는 공업수학 2 강의의 **DFT(이산 푸리에 변환), FFT(고속 푸리에 변환), IFFT(역 푸리에 변환)** 실습을 위한 인터랙티브 웹 데모입니다.

### 핵심 기능
- **소리 실험**: 피아노 건반을 누르면 실시간으로 FFT 스펙트럼을 그래프로 시각화
- **잡음 제거**: FFT로 신호를 분석하고 고주파를 감쇠한 후 IFFT로 원래 신호로 복원
- **이미지 실험**: 2차원 패턴(줄무늬, 격자, 대각선)의 푸리에 스펙트럼을 비교
- **Claude Code 시연**: 이 데모를 어떻게 만들었는지 단계별 프롬프트 예시 제공

## 🎯 사용법

### 1️⃣ 랜딩 페이지 (`index.html`)
- **실습 데모 열기**: 인터랙티브 실습 데모로 이동
- **강의 자료 보기**: Notion 강의 슬라이드 링크
- **Claude Code로 만들기**: 이 데모를 만들 때 사용한 프롬프트 예시 확인

### 2️⃣ 실습 데모 (`demo.html`)

#### 소리 실험 탭
1. **필터 방식** 또는 **FFT → IFFT 방식** 선택
2. **잡음 재생** 버튼으로 화이트 노이즈 추가
3. 피아노 건반을 눌러 소리 재생
   - 좌측 그래프: 시간 영역 파형 비교 (파랑=원본, 보라=처리 후)
   - 우측 그래프: 주파수 영역 스펙트럼 (파랑=원본, 보라=남은 성분, 빨강=감쇠 구간)
4. **감쇠 시작** 슬라이더로 잡음 제거 강도 조절

#### 이미지 실험 탭
1. **무늬 바꾸기** 버튼으로 패턴 전환
   - 세로 줄무늬: 가로 방향 주파수 성분 강조
   - 격자무늬: 가로/세로 두 방향 성분 나타남
   - 대각선 줄무늬: 대각선 방향 성분 시각화
2. 좌측: 원본 이미지 (공간 영역)
3. 우측: 2D 푸리에 스펙트럼 (주파수 영역)

## 🛠️ 기술 스택

- **HTML5 Canvas**: 실시간 그래프 렌더링
- **Web Audio API**: 소리 신호 생성 및 재생
- **FFT 알고리즘**: Cooley-Tukey 알고리즘 구현 (자체 코드, 외부 라이브러리 없음)
- **순수 JavaScript**: 외부 의존성 없는 단일 파일 애플리케이션

## 📝 학습 목표

이 데모를 통해 학습할 수 있는 것들:

1. **DFT 개념**: 시간 영역 신호를 주파수 영역으로 변환
2. **FFT 효율성**: O(N log N) 알고리즘으로 실시간 처리 가능
3. **신호 처리**: 고주파 필터링으로 잡음 제거
4. **2D 변환**: 이미지의 패턴을 주파수로 분석
5. **웹 개발**: Canvas, Web Audio API 실습

## 🔧 개발 정보

### FFT 구현
자체 구현된 Cooley-Tukey FFT 알고리즘:
- 입력 크기: 2의 거듭제곱 (2048 사용)
- 시간복잡도: O(N log N)
- 역변환(IFFT) 지원

### 웹 오디오 설정
- 샘플링 레이트: 44.1 kHz (표준 CD 품질)
- 분석기 FFT 크기: 2048 포인트
- 스무딩 계수: 0.78 (시각적 안정성)
